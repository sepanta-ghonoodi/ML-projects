# Machine Learning Assignments – Overview

Five projects covering probabilistic models, optimization, kernel methods, clustering, neural networks, and transfer learning.

- **Project 1** – Bayes vs. randomized rules, Gaussian classifiers, MLE for Bernoulli/Poisson, MSE from log‑likelihood.
- **Project 2** – Line search (Armijo, Wolfe), Newton’s method, SGD vs. batch, AdaGrad, constrained optimization.
- **Project 3** – SVM dual & kernel trick, RBF feature space, ID3 decision trees, XOR failure, class imbalance.
- **Project 4** – K‑means, agglomerative clustering, PCA/KPCA/LDA choice, feature selection (SFS, RFE, Lasso), image segmentation.
- **Project 5** – MLE, logistic SGD, bias‑variance, perceptron transformations, dead ReLU, Xavier init, transfer learning on CIFAR‑10 (VGG‑11).
